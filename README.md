# Loopy Support

This is the official support repository for Loopy.

Use GitHub Issues to report bugs, request features, or suggest improvements.

## Before Submitting an Issue

Please search existing issues before creating a new one.

When reporting a bug, include:

- Device model
- iOS version
- Loopy app version
- Steps to reproduce the issue
- What you expected to happen
- What actually happened
- Screenshots or screen recordings, if available

[Open a new issue](https://github.com/LoopyApp/loopy-support/issues/new)

## Privacy

This repository is public. Do not include personal information, private file names, email addresses, or sensitive screenshots in an issue.

For private inquiries, please contact us by email.
